# Logic Gates

## Objective
Implement and verify the seven basic logic gates using Verilog.

## Gates Implemented
- AND
- OR
- NOT
- NAND
- NOR
- XOR
- XNOR

## Verification
Each gate has its own self-contained testbench.

## Tools Used
- Verilog HDL
- Icarus Verilog
- GTKWave

## Learning Outcomes
- Continuous assignment (`assign`)
- Module creation
- Port declaration
- Testbench writing
- Logic verification
